## 4. 真实缺陷（本轮的坑）

| 编号 | 现象 | 根因 | 处置 |
| --- | --- | --- | --- |
| D1 | 首次 `rag_smoke` 上传报 1062 `Duplicate entry '7001-15e8…' for key 'uk_user_sha'` | 唯一键包含软删除行，而 `get_document_by_sha` 只看 `is_delete=0` | 新增 `_revive_document`：命中软删行时恢复为排队并清空旧切片；冒烟第二次运行命中同一 id 即验证 |
| D2 | 上传成功但文档永远 `status=0` | `create_app` 里 `build_handlers(memory, repository)` 漏传 `docs`，worker 没有 ingest 处理器 | 传 `docs=document_service`；日志出现 `task doc ingested` |
| D3 | 迁移只建出 `doc_chunk` | 按 `;` 切分后"注释 + 第一条 DDL"整段以 `--` 开头被跳过 | 先剔除整行注释再切分；输出 `tables: ['doc_chunk', 'doc_file']` |
| D4 | 迁移脚本 `parents[1]` 指到 `backend-agent/` | 目录层级算错 | 改 `parents[2]` |
| D5 | 端到端引用为空 | 桩模型把 `query` 写死成「疫苗」，与刚上传的体检报告无关 | 桩改为用用户原话当检索词；同时补 `chat.tool.search_docs` 文案 |
| D6 | `p1_smoke` 的 429 用例假失败 | 串行 30 次被 RAG/工具拖到跨分钟，分钟窗口重置 | 改为 30 并发打满窗口（`ThreadPoolExecutor`） |
| D7 | 每跑一次测试，cwd 里就多出一批空目录 `pet-docs-*` | `tests/conftest.py` 的 `make_settings` 每次 `tempfile.mkdtemp` 且从不清理 | 统一挂到会话级 `_DOCS_ROOT` 下，并用 autouse 会话 fixture 结束时 `rmtree`；复跑后残留目录为 0 |

## 5. 已知缺口

1. 图片/视频在**本机**不可用（缺 `tesseract`、`ffmpeg`）；代码路径与降级原因已实现，未在真机跑成功案例。
2. 向量存 `MEDIUMTEXT` + 暴力余弦，文档量上万后需要迁移到 pgvector / 向量库。
3. 中文 hash 嵌入只是"能离线跑"的基线，语义召回明显弱于真模型；生产应切 `embed_backend=openai` 并做召回评测。
4. 没有"重新解析"接口：改了 embedder 需要重传或手工清库。
5. 前端未做上传进度条与 `status=3/4` 的详情页，只给 toast。
