# S1.33 管理员统一模型配置

- 日期：2026-11-18
- 对应：用户需求（管理员统一配置模型），BACKLOG C10
- 状态：已完成（管理端页面未做浏览器点击，见「已知局限」）

## 结论

模型配置从只读环境变量升级为管理端可操作：管理员可测试连接、保存并热应用，Key 加密落库/落盘且只回显末 4 位；数据库没有启用配置时回退 `PET_AGENT_LLM_*`。后端全量 `pytest` 258 例（257 通过 + 1 跳过），新增模型配置测试 9 例；管理端 `vue-tsc -b` 与 `npm run build` 通过。管理端页面未做浏览器点击（8080 被用户 Java 后端占用），e2e 套件未重跑。

## 做了什么

### 后端

- 新增 `backend-agent/app/model_config/`：
  - `crypto.py`：`ConfigCipher`，HMAC-SHA256 计数器模式密钥流 + HMAC-SHA256 Encrypt-then-MAC；密文格式 `v1:` + 16B nonce + 32B tag + ciphertext；主密钥优先 `PET_AGENT_CONFIG_SECRET`，否则自动生成 `data/model-config.key` 并设为 0600；解密用 `hmac.compare_digest`。
  - `store.py`：`ModelConfig`、`InMemoryModelConfigStore`（JSON 原子写）、`MySqlModelConfigStore`（单行 `agent_model_config`，`INSERT ... ON DUPLICATE KEY UPDATE`）、`create_model_config_store(settings)`。
  - `service.py`：`describe/save/apply/bootstrap/test_connection/aclose`；保存前构建候选模型，构建失败不落库；空 Key 沿用旧 Key；禁用/无配置回退 env；热切换回调；Key 掩码只留末 4 位。
- `config.py`：新增 `model_config_enabled=True`、`config_secret`（`repr=False`）、`model_config_key_file`、`model_config_file`；生产启动护栏改为「env key 或开启管理端配置」。
- `api/schemas.py`：`ModelConfigIn/Out/TestOut`；`HealthOut.model_source`。
- `api/routes.py`：`GET/PUT /agent/admin/model-config`、`POST /agent/admin/model-config/test`；均走 `_admin_identity`；保存/测试写 `agent.admin` 审计，不返回 Key/密文；`healthz`/`readyz` 改用 `_runtime_model_ready()`。
- `api/app.py`：创建 `ModelConfigService`，lifespan 里 `bootstrap()`，回调 `apply_runtime_model` 重建 graph 并 `runner.reconfigure`；服务关闭时关闭 current/retired model。
- `runtime/runner.py`：`reconfigure()` 热替换；`_drive` 开始时固定本次 run 的 `model/graph` 局部引用，避免在途 run 混用新旧模型。
- `backend/sql/v2.18-agent-model-config.sql`：`agent_model_config` 单行表（provider/base_url/model/api_key_cipher/enabled/updated_by/update_time）。

### 管理端

- `src/api/agent.ts`：`AdminModelConfig`/`AdminModelConfigPayload`/`AdminModelConfigTestResult` 与三个管理接口。
- 新增 `src/views/agent/ModelConfig.vue`：provider/base_url/model/API Key/启用开关；「测试连接」「保存并应用」；展示运行时模型、来源（db/env/none）、Key 掩码、更新时间、fallback 与错误。
- `src/router/index.ts` 增加 `agent/model`；`src/layout/Sidebar.vue` 增加「模型配置」入口。
- 页面三个测试选择器：`model-config-page/model-config-test/model-config-save`。
- 表单校验区分「数据库已保存 Key」与「env 兜底 Key」：env 有 Key 不代表可以启用数据库配置，启用时仍必须新填 Key。

### 测试

- 新增 `backend-agent/tests/test_model_config.py` 9 例：非管理员 403、空配置 source none、保存掩码并热应用、空 Key 沿用旧 Key、禁用回退 env、测试连接缺 Key 400、cipher 往返/篡改、落盘无明文、禁用且无 env 时 readyz 503。
- 修复一个真实回归：`test_readyz_degrades_without_model_key` 曾因「注入 ScriptedModel 但 env 无 key」误判 200；现按运行时来源判定。
- 修复热切换边界：`_drive` 原先把 `self._model/self._graph` 分散使用，配置切换可能让在途 run 用旧图跑一半、新模型收尾；现固定为局部引用。
- `.gitignore` 增加 `pytest-of-*/`：本机 `%TEMP%` 不可写时 pytest 会把临时目录落到仓库内，已实测产生 `backend-agent/pytest-of-XiaoNian/`。

## 已知局限

1. **加密是过渡方案**：缺少主密钥轮换、KMS 审计；`data/model-config.key` 丢失后已存 Key 不可恢复。
2. **base_url 可指向内网**：当前依赖管理员可信，未做私网地址/域名白名单，存在 SSRF 面。
3. **MySQL 路径未真机验证**：DDL 与 `MySqlModelConfigStore` 只做了代码审查与接口契约，没有 DSN 环境。
4. **页面未浏览器验收**：`vue-tsc`/build 只能证明类型与打包，不能证明交互；等 8080 空闲后应补一条 Playwright 管理端用例。
5. **热切换并发时序**：已固定 `_drive` 的局部 model/graph，但没有专门的「run 执行中切换配置」并发测试。
