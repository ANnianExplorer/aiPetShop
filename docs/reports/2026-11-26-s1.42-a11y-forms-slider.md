# S1.42 · D10 第三刀：表单错误播报与热点卡片键盘化

## 环境

- Windows / PowerShell 7
- Node v24.10.0
- vitest 5.1.0

## 做了什么

1. **新增通用表单错误组件**：`src/components/common/FormError.vue`，`role="alert"`、稳定 `id`、`data-testid="form-error"`，空消息不渲染。
2. **新增表单错误 composable**：`src/composables/useFormA11y.ts`，提供 `errorMessage` / `errorId` / `announce` / `clear`；`announce` 先清空再写入，同一条错误重复提交也会重新播报。
3. **六个表单接入**：Login、SignUp、AddPet、AddReminder、EditProfile、AccountSecurity。
   - 校验失败从纯 Toast 改为表单内 `role="alert"`，输入补 `aria-invalid` / `aria-describedby`。
   - 提交失败后焦点落到首个缺失字段；补齐必填项后错误自动清除。
   - 输入补 `aria-label` 与 `autocomplete`；密码可见按钮补显示/隐藏名称。
   - AddPet 类型按钮、AddReminder 类型/重复按钮补 `aria-pressed`；AddPet 头像上传由 `div` 改为原生 `button`；装饰预览图 `alt=""`；各页返回按钮补可读名称。
4. **TrendingSlider**：标题与区域用 `aria-labelledby` 关联；「查看全部」和话题卡片改为 `RouterLink`；卡片补「查看话题：{title}」名称；封面图 `alt=""`；左右按钮补名称并在不可前进/后退时 `disabled`；圆点 `aria-hidden`；自动播放在 hover/focus 时暂停，`prefers-reduced-motion` 下不启动，卸载时清理定时器。
5. **PostDetail**：作者头像与昵称在有 `post.user.id` 时改为 `RouterLink` 进入用户主页，键盘可达；无作者 id 时保持普通容器。
6. **三语 locale**：新增 `a11y.topicCard`、`a11y.viewUserProfile`、`a11y.prevTopic`、`a11y.nextTopic`、`community.trending`、`community.viewAll`、`auth.showPassword`、`auth.hidePassword`、`petForm.uploadAvatar` 共 9 个 key，中/英/日齐全。

## 已知缺口与风险

- `SignUp`、`AddReminder`、`EditProfile`、`AccountSecurity` 已接入同一套错误组件与 composable，并随全量类型检查通过，但未各写独立 spec；共享组件 `FormError` 与 `useFormA11y` 已有单测。
- 对比度扫描与 NVDA/VoiceOver 真机验收仍留在 D10，需要工具/真机，本轮未做。
- `TrendingSlider` 卡片由 `div` 改为 `a`，布局与触控滑动手感尚未做浏览器目视验证；建议下次真机过一遍首页。
- 自动播放仅按索引推进，未按实际滚动宽度计算末位；窄屏下视觉上可能仍有余量，但按钮禁用语义已按索引生效。
- `pet-lumina-app/dist` 为仓库跟踪产物，本轮已重新构建并随提交更新。

## 结论

D10 第三刀完成：六个表单具备可播报的内联错误与焦点管理，热点区域和详情页作者信息可通过键盘访问。D10 剩余项为对比度扫描与真实读屏验收。
