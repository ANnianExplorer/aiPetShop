## 做了什么

### 1. 三只内置动物形象

| 文件 | 内容 |
| --- | --- |
| `pet-lumina-app/src/assets/pet/lumina-cat.svg`（新增） | 橘猫：奶油脸、大眼、粉耳、绿项圈金铃铛、卷尾 |
| `pet-lumina-app/src/assets/pet/lumina-dog.svg`（新增） | 柴犬：立耳、奶油口鼻、吐舌、卷尾 |
| `pet-lumina-app/src/assets/pet/lumina-bunny.svg`（新增） | 奶油兔：长耳、门牙、绒球尾 |

三张都是 200×240 透明底 SVG，同一套线条与配色。`src/utils/petSprite.ts` 负责映射：

- `cat` → 橘猫
- `dog` → 柴犬
- `other` / 未知 / 未选宠物 → 奶油兔 / 橘猫（未知类型回退猫）
- PetStudio 自定义精灵图仍优先，内置图只在没有自定义图时兜底

旧的 `src/assets/pet/lumina.svg`（绿发人形）已无引用，本轮删除。

### 2. 右键动作菜单

`src/components/pet/DeskPet.vue`：

- 桌宠根节点监听 `@contextmenu.prevent.stop`，右键打开菜单，不再弹浏览器默认菜单。
- 保留长按 520ms 打开；右键、长按、键盘统一在宠物上方展开，`position: fixed` 并夹在视口内。
- 菜单 8 项：吃白饭、跳舞、转圈、伸懒腰、摸摸头、打个盹/叫醒它、去聊天、收起。
- 动作复用引擎已有片段：`act.eat`、`act.dance`、`act.spin`、`act.stretch`、`click.pat`；无新动画。
- 睡眠时前 5 个动作禁用，只留「叫醒它 / 聊天 / 收起」。
- 键盘：桌宠可聚焦，Enter / ContextMenu 键 / Shift+F10 打开菜单并聚焦第一个可用项；Escape 关闭并还焦点；点击菜单外部关闭。
- 打开菜单时清掉当前气泡，避免气泡被菜单压住。
- 菜单按钮是原生 `button`，图标 `aria-hidden`，按钮文本可读；`role="group"` + `aria-label`。

### 3. 文案

三份 locale（`zh-CN` / `en-US` / `ja-JP`）的 `pet` 节新增：

- `ariaNamed`（带宠物名字的桌宠名称）
- `menu.title` / `menu.hint` / `menu.dance` / `menu.spin` / `menu.stretch` / `menu.pat`
- `say.dance` / `say.spin` / `say.stretch` / `say.pat`

说明：把 `vue-tsc` / `vitest` / `build` 并行串起来跑时，曾出现 14 个 `[vitest-pool] Failed to start forks worker ... Timeout waiting for worker to respond` 的启动超时（只完成 12 个文件 / 88 例），无断言失败；随后单独重跑 `npx vitest run`，26 文件 / 215 例全部通过。判定为本机进程/资源竞争导致的跑批抖动，不是用例失败。

覆盖的关键断言：

- 右键触发 `contextmenu` 且 `defaultPrevented === true`，菜单出现，含跳舞/转圈/伸懒腰/摸摸头。
- 点「跳舞」后气泡为「本鱼给你扭两下！」。
- 点「打个盹」后前 5 项 `disabled`，点「叫醒它」后恢复。
- `cat` / `dog` / `other` 分别渲染 `data-sprite-kind="cat" / "dog" / "bunny"`，`aria-label` 含宠物名字。
- Escape 与点菜单外部都会关闭菜单。
- `petSprite` 三类型映射、未知类型回退、三张图资源互不相同。

测试过程中发现并修掉一个时间依赖：桌宠问候按当前小时选「睡觉/陪你」文案，23 点跑测试会失败；`DeskPet.spec.ts` 的 `beforeEach` 固定 `Date.prototype.getHours` 为 10，避免夜间测试漂移。

## 已知缺口与风险

- **图标字体依赖**：Material Symbols 来自 Google Fonts；断网时 ligature 会退化成英文名。已加 `overflow:hidden` 防止撑破按钮，但离线图标不可用是全站既有问题，本轮未扩大范围。
- **真实触屏未验收**：jsdom 验证事件契约，Edge headless 验证鼠标右键；iOS Safari 长按/右键手感、长按 520ms 与拖拽的冲突仍需真机确认。
- **自定义精灵图优先**：如果用户在 PetStudio 生成过人形精灵，仍会显示那张；这是用户主动选择，内置动物不会覆盖。
- **极端小屏**：菜单高度约 220px，视口高度不足时会被夹到左上角，可能盖住宠物；属于降级行为。
- **未跑后端测试**：本轮没有改 `backend` / `backend-agent`，按「改到哪测到哪」原则只跑前端；不把前端通过说成后端也通过。

## 结论

默认桌宠从绿发人形换成按宠物类型选择的猫/狗/兔，右键即可在宠物上方打开 8 项动作菜单，键盘和读屏可用；测试、类型检查、构建均通过，真实浏览器目检通过。可以合并。
