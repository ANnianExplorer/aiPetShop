# S1.20 桌宠 v2（BACKLOG C6 重做）交付报告

日期：2026-11-08
状态：已完成
关联：`docs/plans/s1.20-deskpet-v2.md`、BACKLOG C6

## 1. 为什么要重做

S1.19 的桌宠是一个扁平 SVG 图形 + 单条 CSS 动画，用户的判断很直接：

> 你这桌宠不行啊，不是我想要的，我想要的是和 dsh-pet 一样的效果啊，有动画，而不是你这种僵硬难看的桌宠，dsh-pet 的桌宠才是好看又灵动感

对照 dsh-pet（右下角一个 anime 风格 Q 版角色，持续呼吸、眨眼、尾巴摆动、跟随视线）后确认：差距不在配色或尺寸，而在**运动模型**——单元素整体缩放不可能产生「活着」的感觉。

因此 v2 的目标不是调参，而是换结构：**把角色拆成可独立运动的部件，再给每个部件配一条有相位差的循环动画**。

## 2. 交付内容

## 4. 真实问题

| 编号 | 问题 | 处置 |
| --- | --- | --- |
| D1 | `@vue/test-utils` 的 `trigger('pointerdown', { clientX })` 抛 `TypeError: Cannot set property clientX of #<MouseEvent> which has only a getter` | 改为 `new MouseEvent(type, { clientX, clientY, bubbles: true })` + `dispatchEvent` |
| D2 | `element.animate` 在 jsdom 里不存在，单击测试抛 `TypeError: el.animate is not a function`，连带爱心不生成 | `jump()` 里判 `typeof el.animate !== 'function'` 直接跳过动画，点击反馈（爱心 + 气泡）不受影响 |
| D3 | 首版 `pointer-events:none` + 只有 `.pet-body` 绑事件，真实点击打不到宠物 | 容器改 `pointer-events:auto`，事件上提到容器，`z-index` 45（低于 FAB 50、高于内容） |
| D4 | 想复用 dsh-pet 素材，解析 `app.asar` 三次失败（pickle 长度/JSON 起点对不上） | 放弃提取第三方美术资源，改为自绘 SVG——既不侵权，也不引入不可控依赖 |

## 5. 已知边界

1. 不是 Live2D/VRM：没有骨骼与网格形变，动作是 CSS 关键帧 + JS 驱动的瞳孔偏移，观感上限低于 Live2D。
2. 只用了真实字段（名字/健康分/步数/喂食/未读提醒/小时），没有编造状态。
3. 拖动只在窗口内吸附，不跨窗口、不记忆多屏坐标。
4. 夜间 `sleepy` 只是闭眼 + 放慢呼吸，没有切换场景（睡觉姿势、被窝）。
5. 没有音效与语音。
