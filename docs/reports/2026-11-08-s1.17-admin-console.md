## 3. 本轮真实问题

| 编号 | 现象 | 根因 | 处理 |
| --- | --- | --- | --- |
| D1 | 队列页用真 Java token 调 `/agent/admin/tasks` 返回 403 | 8099 当时指向 `tests.stub_java`，桩只认 `token-*` | 8099 改指真后端 `PET_AGENT_BACKEND_BASE_URL=http://127.0.0.1:8080/api/v1` |
| D2 | 改指真后端后仍 403 | Java `/api/v1/auth/current` 返回体**没有 `role` 字段**（`LoginUserVO` 缺字段、`getLoginUserVO` 未 set），Agent 只能当 `user` | `LoginUserVO` 增 `role`，`getLoginUserVO` 回填；重启 8080 后 `role=admin` |
| D3 | 图谱只有文字标签、看不到节点圆点 | `series.symbolSize` 用回调取 `params.data.kind`，本版 vue-echarts 下回调拿不到 params → 返回 `undefined` → 节点 0 尺寸 | 改 `symbolSize` 常量 + 每个节点 `data.symbolSize` 按层级给值，并补 `data.value` 占位 |
| D4 | 侧栏看不到「长期记忆 / 知识图谱 / 队列运维」 | 菜单 15 项超出可视高度，`nav` 为 `overflow-y-auto`（可滚但无提示） | 侧栏紧凑化（`mb-6` / `gap-1` / `py-2.5` / `text-[13px]` / `no-scrollbar`）；验证滚动后可见并可点 |
| D5 | 首次打开 `/#/agent/queue` 空白 | dev server 冷启动 + 懒加载 chunk 首次编译慢（非错误） | 等待后正常；记录为「空白先等 3–5 秒再判死」 |
| D6 | 旧 3000 进程残留导致侧栏显示旧版 | 上一轮 dev server 未退出 | `Get-NetTCPConnection -LocalPort 3000` 找 pid 后 `Stop-Process` 重启 |

## 4. 已知缺口

1. 图谱只画 Agent 侧数据，Java 侧业务实体（宠物档案、健康记录）未入图——跨服务拼图需要先把权限边界设计清楚。
2. 节点颜色目前统一（本版 ECharts 的 `data.itemStyle` 未生效），三层靠尺寸与标签区分；后续可换 `graphic` 自绘或升级 ECharts。
3. 队列页「已消费/失败」是**本进程启动后**的计数，重启归零；跨重启的累计需要落库（当前只有 `tool_call_log` 与死信列表可查）。
4. 记忆页只按 `user_id` 查询，没有列表页（不知道有哪些用户有记忆）；需要时可用 `GET /agent/admin/sessions` 反查。
5. 无自动化前端 e2e（仍是 Edge 手点），CI 里只有类型检查与构建。

## 5. 复现步骤

```powershell

cd backend; mvn -B -o spring-boot:run     # 需要 backend/application-local.yml 提供数据库口令

# 2) Agent（8099，真后端身份 + mysql + redis）
cd backend-agent
$env:PET_AGENT_REPO_BACKEND="mysql"; $env:PET_AGENT_MYSQL_DSN="mysql://root:<口令>@127.0.0.1:3306/petlumina"
$env:PET_AGENT_BACKEND_BASE_URL="http://127.0.0.1:8080/api/v1"
$env:PET_AGENT_TASK_BACKEND="redis"; $env:PET_AGENT_EVENT_BACKEND="redis"; $env:PET_AGENT_RATE_LIMIT_BACKEND="redis"
.\.venv\Scripts\python -m uvicorn app.main:app --host 127.0.0.1 --port 8099

# 3) 管理端（3000）
cd ..\pet-lumina-web
$env:VITE_API_BASE_URL="http://127.0.0.1:8080/api/v1"; $env:VITE_AGENT_BASE_URL="http://127.0.0.1:8099"
npm run dev -- --host 127.0.0.1 --port 3000

# 4) 浏览器：/#/login 用管理员账号（13800000001/123456）→ /#/agent/queue、/#/agent/memory、/#/agent/graph
```
