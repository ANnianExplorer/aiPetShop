## 做了什么

### 1. 路由标题（31 个具名路由）

- 新增 `pet-lumina-app/src/utils/pageTitle.ts`：
  - `PAGE_TITLE_KEYS`：路由 name → `pageTitle.*` 的 31 条映射；
  - `titleKeyForRouteName` / `formatDocumentTitle` / `applyDocumentTitle`：纯函数，副作用只写 `doc.title`；
  - `installDocumentTitle`：注册 `router.afterEach`，并 `watch` 当前语言，切语言时用当前路由重算标题；返回停止函数。
- `pet-lumina-app/src/router/index.ts`：安装 `installDocumentTitle(router, key => i18n.global.t(key), i18n.global.locale)`。
- 三份语言包新增 `pageTitle` 节（各 31 键，中文 / 英文 / 日文）。

### 2. 卡片键盘可达与图片 `alt`

- `pet-lumina-app/src/components/community/PostFeed.vue`：
  - 卡片主体 `div @click` → `RouterLink`，整卡可 Tab 聚焦、Enter 进入详情，`aria-label` 含作者与摘要；
  - 头像 `alt=""`，帖子图 `alt` 含作者，作者缺失回退「匿名用户」；
  - 更多 / 点赞 / 评论 / 收藏 / 分享按钮补 `aria-label`（点赞与评论带当前数量），图标 `aria-hidden`。
- `pet-lumina-app/src/components/lifelog/LogCard.vue`：
  - 整卡改 `RouterLink` + `aria-label="查看生活记录：<标题>"`；
  - 记录图补 `alt`，类型图标容器 `aria-hidden`。
- `pet-lumina-app/src/views/community/Community.vue`、`views/lifelog/LifeLog.vue`：
  - 头像 `alt=""`；通知按钮补名称；搜索框补 `aria-label`，搜索图标 `aria-hidden`。
- `pet-lumina-app/src/views/community/PostDetail.vue`、`views/lifelog/LifeLogDetail.vue`：
  - 正文图补 `alt`；返回 / 分享 / 更多按钮补名称；动作按钮补 `aria-label`。

### 3. 测试

新增 3 个测试文件、16 例：

- `src/utils/pageTitle.spec.ts`（9 例）：格式化、未知路由、真实路由表全覆盖、三语 key 齐全且非空、locale 切换重算、停止函数。
- `src/components/community/PostFeed.a11y.spec.ts`（4 例）：整卡是 `<a href="/post/p1">`、名称含作者与摘要、头像空 `alt`、内容图描述、按钮名称、已点赞/已收藏语义、匿名作者回退。
- `src/components/lifelog/LogCard.a11y.spec.ts`（3 例）：整卡是 `<a href="/log/l1">`、名称含标题、记录图描述、装饰图标隐藏、无图时仍可导航。

## 已知缺口与风险

1. **对比度扫描未做**：本轮只做语义与键盘可达，颜色对比度仍需工具扫描 + 人工判断。
2. **真实读屏未验收**：NVDA / VoiceOver 的实际播报顺序、链接名称是否冗余，需真机确认；jsdom 只能证明 DOM 契约。
3. **遗留键盘路径**：`TrendingSlider` 的「查看全部」与话题卡片、详情页作者头像点击仍未键盘化；已写回 BACKLOG。
4. **标题只在路由完成后更新**：首屏进入前仍是 `index.html` 的 `PetLumina`，属预期；若未来做 SSR/预渲染需另行处理。
5. **未跑后端测试**：本轮无 `backend-agent` / `backend` 改动，按「改动到哪跑到哪」只跑 App 全量；不把未运行的后端测试写成通过。
6. **视觉回归未做**：`div` → `RouterLink` 后依赖 `class="block"` 与继承样式，未做截图对比；构建与 DOM 测试通过，但样式需浏览器目视确认。

## 结论

D10 第二刀按计划交付：31 个路由有可随语言切换的 `document.title`，社区/生活记录卡片成为真正的链接并带可读名称，主列表与详情页图片/图标按钮语义补齐。App 全量 207 tests、`vue-tsc -b`、`npm run build` 均为真实退出码 0。剩余项（对比度、真实读屏、`TrendingSlider`、作者头像键盘化、表单错误播报）已更新进 `docs/BACKLOG.md`。
