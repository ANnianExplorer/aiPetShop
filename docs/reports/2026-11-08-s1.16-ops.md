## 2. 交付三项

### 2.1 B3 在途消息可见性超时回收

| 位置 | 改动 |
| --- | --- |
| `app/tasks/redis_queue.py` | 新增 `:claimed` ZSET（score = 取用时刻）、`zadd/zrem/zrangebyscore` 依赖；`receive` 登记、`ack`/`nack` 清理；新增 `sweep(topics, older_than_s)`：过期条目从 `:processing` 搬回主队列并 `attempt+1`，`LREM` 未命中则只清登记（自愈） |
| `app/tasks/worker.py` | 新增 `_sweep_loop`（可关闭）与 `swept` 计数；`start()` 一并启动巡检、`stop()` 一并取消 |
| `app/tasks/base.py` | 协议新增 `sweep`，写明 at-least-once 与"内存实现返回 0、不假装能扫" |
| `app/tasks/inprocess.py` | `sweep` 返回 0 |
| `app/config.py` | `TASK_VISIBLE_TIMEOUT_S=120`、`TASK_SWEEP_INTERVAL_S=60` |

判定依据是**取用时刻**而不是消息创建时间——否则积压久的消息一被取走就会被误判超时。

### 2.2 B5 最小 Prometheus 指标

| 指标 | 类型 | 标签 |
| --- | --- | --- |
| `pet_agent_http_requests_total` | counter | `method` `path`(路由模板) `status` |
| `pet_agent_http_request_duration_seconds` | summary | `method` `path` |
| `pet_agent_runs_total` | counter | `route` `status` |
| `pet_agent_tool_calls_total` | counter | `tool` `ok` |
| `pet_agent_queue_depth` | gauge | `topic` |
| `pet_agent_tokens_total` | counter | `direction` |

- 新增 `app/core/metrics.py`（线程安全、`render()` 输出 0.0.4 文本、`reset()` 供测试）；
- `RequestContextMiddleware` 记 HTTP 两项，`path` 取 `request.scope["route"].path`；
- `AgentRunner` 成功/失败记 `runs_total`、成功记 `tokens_total`；
- `ToolGateway._finish` 记 `tool_calls_total`；
- `GET /metrics`（`include_in_schema=False`）渲染时读取各 topic 深度；不加鉴权、不含用户内容。

### 2.3 B7 记忆可删、可导出

- `AgentRepository.delete_memory_fact(user_id, pet_id, key) -> bool`：
  - 内存实现按 `(user, pet|"", key)` 槽位删除；
  - MySQL 实现 `DELETE FROM memory_fact WHERE user_id AND pet_id AND fact_key`（物理删除，`pet_id=None` 走 0 槽位）。
- `DELETE /agent/memory/me?key=&pet_id=` → `{"deleted": true, "key": ...}`；不存在 404。
- `GET /agent/memory/me/export?pet_id=` → `{"version": 1, "exported_at", "pet_id", "facts": [...]}`，事实带中文 `label`。

## 5. 已知缺口

1. 巡检回收是 at-least-once：极慢任务（> 可见性超时）会被重放一次，依赖消费端幂等；生产建议按最慢 handler 调整阈值。
2. `/metrics` 无鉴权，生产需在网关/安全组限制来源。
3. 指标为进程内累计，多副本需 Prometheus 按 instance 聚合（B2 尚未验证）。
4. 记忆物理删除不可恢复；需要留底请先调导出接口（产品化时应在 UI 提示）。
5. 本轮未改前端，两端构建未重跑（沿用 A3 基线）；前端若接入"删除记忆/导出"需另开 UI 任务（已在 BACKLOG 标注）。
