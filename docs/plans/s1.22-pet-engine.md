## 1. dsh-pet 到底怎么做的（源码事实，不是猜测）

| 层 | 关键实现 | 出处 |
| --- | --- | --- |
| 素材 | **109 个 VP9-alpha `.webm`（640×360），共 52.7MB**，中文命名（`待机呼吸休闲`、`被鼠标拖拽悬空反馈`、`吃白饭`、`吃Token`、`睡觉-开始/循环/起来`、`余额-钱袋满溢`…），扩展名按 UA 探测 `.webm`/`.mov` | `assets/*.webm`、`animation/media.ts` |
| 播放 | `<video>` **A/B 双缓冲**：整个文件 `fetch` 成 blob，`src=objectURL`，`loadeddata` 后加 `.is-front` 交叉淡入，旧元素 `pause()` 并清 `onended`（防残留 ended 掐断前台）；`loop=!once`、`muted`、`playsInline` | `animation/animation.ts` |
| 透明 | 素材「透明」区 alpha 实测恒为 1/255，注入 SVG 滤镜 `feFuncA type=linear intercept=-1/255` 扣一档归零 | `pet/css.ts` |
| 编排 | `pickNext()` → `rollKind(roll, weights==={idle:10,turn:5,move:5})` 分档 → 动作池按 weight 加权；**片段播完**由 `decideEndedCue` 决下一步：`work-rotate`/`work-replay`/`event-done`/`turn`（翻转朝向）/`interaction-done`/`random` | `card/animation-flow.ts`、`animation/cues.ts` |
| 状态 | 六档工作状态 `thinking/working/result/waiting/success/error`，由 turn/start、tool/call、tool/result、approval/asked、turn/end、error 驱动；事件动画播完要**接回**工作档，不许丢 | `shared/work-status.ts`、`events.workStatus` |
| 睡觉 | 独立状态机 `start → loop → end`；入睡过渡里取消不播 end；loop 段收到 ended 说明被顶掉，要**点名重播 loop** | `card/sleep-machine.ts` |
| 物理 | 拖拽=过阻尼弹簧（K=200/C=30，ζ≈1.06）；甩出 `v_max·(1-e^(-v/v_max))` 封顶 3600；8px 子步防穿模；落地 `restitution=.78` 反弹 + 摩擦 + 220ms 落地挤压；命中区 640×360 里 `{x0:200,y0:50,x1:440,y1:335}`，至少留 24px 可点 | `shared/physics/*`、`motion/geometry.ts` |
| 交互 | 单击回应（5 种随机）、双击甩出/收起、长按菜单、气泡 10s、碎碎念 300s、余额/工作时长事件刷新 | `card/*`、`bubble.ts` |

## 2. 本轮怎么复刻

| 层 | 本项目的做法 | 为什么这么选 |
| --- | --- | --- |
| 渲染 | **canvas 2D**，`Pose{scaleX,scaleY,rotate,offsetX,offsetY,alpha,shadow,mirror,props}` + 13 种矢量道具 | 没有视频素材；用程序化姿态复现「呼吸/眨眼/张望/跳跃/落地挤压」等 22 段动作，体积 0 素材 |
| 编排 | 同构照搬：`rollKind` 权重分档、`decideNextClip`、`decideEndedCue` 六种回链、`workClipFor` 六档、`sleep` 三段式 | 参考实现的编排不变量就是「不卡帧、不丢状态」的根因 |
| 物理 | 同参数复刻：弹簧/甩出封顶/子步/反弹/摩擦/挤压/命中区 24px | 手感是数值问题，参数照抄最稳 |
| 交互 | 单击台词 4 种、双击去聊天、长按菜单（吃白饭/打盹/叫醒/去聊天/收起）、气泡、28s 碎碎念、`prefers-reduced-motion` 降级 | — |
| 工作状态 | `src/pet/signal.ts` 极简订阅；`ChatView.handleEvent` 按 SSE 事件 publish，`finally` 兜底 `error` | 桌宠全局挂 `App.vue`（不只在首页），否则对话页收不到状态 |
| 物理/环境耦合 | 引擎每帧把位移写 `root.style.transform`，气泡跟着走；位置存 `{rx,ry}` 归一化，窗口尺寸变了也不跑偏 | 参考实现同样把 transform 交给外层壳 |

## 3. 与 dsh-pet 的差异（诚实版）

1. **没有 109 段视频素材**：他们的「好看」一半来自美术逐帧渲染；本项目是单个静态形象 + 程序化姿态。要完全一致必须引入其素材，而 README 写的是「代码 MIT；**素材禁止商用**；二创公开渠道须署名」——需要你点头才做。
2. **动画是参数化而非逐帧**：呼吸/眨眼/跳跃能到「有生命感」，但做不出「原地玩魔方」「鲸鱼吐泡泡」这种整段表演。
3. **没有桌面 Helper 进程**：dsh-pet 有 `runtime/` 桌面侧把宠物钉在系统桌面；本项目只在网页里（H5/PWA）。
