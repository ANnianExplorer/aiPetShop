# S1.20 桌宠 v2：分层矢量角色 + 持续微动（对齐 dsh-pet 观感）

**状态**：已完成（2026-11-08）。交付报告：[`docs/reports/2026-11-08-s1.20-deskpet-v2.md`](../reports/2026-11-08-s1.20-deskpet-v2.md)

## 0. 为什么重做

用户实拍对比后判定上一版不合格：上一版是**单层扁平 SVG + 5 组 CSS 关键帧**，静态感强；
参照物 `dsh-pet`（截取自 DSH `66324` 窗口右下角）是 **anime 比例 Q 版角色**，有持续微动与情绪反应。

差距不是参数问题，是**运动模型**问题：

| 维度 | 上一版 | dsh-pet / 本版目标 |
| --- | --- | --- |
| 造型 | 扁平猫头（一个圆 + 两个三角耳） | Q 版角色：大头、大眼、刘海 + 侧发、身体、尾巴 |
| 运动 | 5 组互相独立的 CSS 关键帧 | **分部件运动链**：呼吸(体) / 发丝滞后摆动(头) / 尾巴钟摆(根) / 眨眼随机(眼) / 耳抖(耳) |
| 交互 | 点击换一句台词 | 视线跟随指针、点击跳跃 + 爱心粒子、拖拽换位、双击收起、夜间 zzz 睡眠 |
| 连贯性 | 每 4.2s 一次气泡 | 微动永不停止；台词只在"情绪切换/交互"时出现 |

## 1. 顶层设计

```
DeskPet.vue（壳：位置 / 隐藏 / 气泡 / 粒子）
└── 角色层（inline SVG，viewBox 200×240，7 个可动部件组）
    ├── tail      钟摆：rotate ±7°，3.2s alternate（transform-origin: 底部根部）
    ├── body      呼吸：scale(1, 1.015) + 轻微 sway
    ├── arms      待机微摆（左右不同步，避免"机器人同步"）
    ├── head      呼吸带动 + 跟随指针 ±4° 倾斜
    ├── hair      侧发/刘海独立摆动，延迟 0.3–0.6s（滞后的"软"感）
    ├── ears      每 5–9s 随机抖动一次（keyframes + 长 delay）
    └── eyes      眨眼（eyelid scaleY，3–7s 随机）+ 瞳孔跟随指针（±3px）
```

### 1.1 运动参数（写死为常量，可单测）

| 部件 | 参数 | 值 |
| --- | --- | --- |
| 呼吸 | 周期 / 幅度 | 3.6s / `scaleY 1.015` |
| 尾巴 | 周期 / 幅度 | 3.2s / ±7° |
| 发丝 | 周期 / 延迟 | 4.2s、4.8s / 0.35s、0.6s |
| 眨眼 | 随机区间 | 2600–6200ms，闭合 110ms |
| 耳抖 | 随机区间 | 5000–9000ms |
| 视线 | 最大位移 / 平滑系数 | ±3px / `k=0.18` |

### 1.2 交互

| 触发 | 行为 | 记忆 |
| --- | --- | --- |
| 指针移动 | 瞳孔 + 头部朝指针方向偏移（夹紧到 ±1，指数平滑） | 无 |
| 单击 | 跳跃（WAAPI，380ms）+ 3 颗爱心 + 气泡说一句 | 无 |
| 长按拖动 | 角色跟随指针移动，松手吸附到左右下角 | `petlumina-deskpet-pos` |
| 双击 | 收起并写隐藏标记 | `petlumina-deskpet-hidden` |
| 夜间（23–6 点） | 睡眠：闭眼 + `zzz` + 呼吸变慢 | 无 |

### 1.3 降级

- `prefers-reduced-motion: reduce`：关闭所有循环动画，只保留点击反馈与气泡；
- 无 `matchMedia`（JSDOM）：按"不降级"处理，测试走假定时器；
- 组件可被父级 `v-if` 直接移除，不留定时器（`onBeforeUnmount` 全清）。

## 4. 风险

| 风险 | 应对 |
| --- | --- |
| SVG 分部件 transform-origin 在不同浏览器不一致 | 全部用 `transform-box: fill-box` + 显式 `transform-origin`，Chrome/Edge 实测 |
| 持续动画耗电 | 全部 `transform/opacity`，不触发 layout；夜间降频 |
| 角色造型反复调 | 先定 7 组骨架比例，再微调颜色/描边；截图对比后再定稿 |
| 与 FAB/底部导航重叠 | 右下锚点 `right:84px; bottom:104px`，拖拽后吸附到安全区 |
