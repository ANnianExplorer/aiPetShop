# S1.37 管理端按模型分账（BACKLOG D4）

- 状态：实施中（2026-11-21）
- 关联：`docs/BACKLOG.md` D4、`docs/spec/agent-runtime-api.md` §4.5、`pet-lumina-web/src/views/agent/SessionList.vue`
- 批次：S1.37

## 1. 目标

管理端 `/agent/admin/usage` 目前只给出「总量 + 按天」，无法回答「钱花在哪个模型上」。本切片让同一份接口返回 `by_model`：

1. 每个模型（`agent_run.model`）的 runs、prompt/completion/total tokens；
2. 当服务端配置了该模型的单价时，返回按 token 估算的 USD 成本；未配置时返回 `null`，前端显示「未配置」，不臆造价格；
3. 管理端会话工作台在现有四张用量卡下方展示「按模型分账」表，并注明单价配置入口与单位。

## 2. 现状与取舍

- `agent_run.model` 在创建 run 时写入（`app/runtime/runner.py`），是「这次实际用了哪个模型」的可靠口径；不使用当前配置回填历史。
- MySQL 与 memory 两种仓储必须给出相同口径：只统计 `status='succeeded'`、按 `since` 过滤、模型为空归为 `unknown`。
- 价格配置放在服务端环境变量 `PET_AGENT_MODEL_PRICES`（JSON），而不是管理端可写配置：
  - 价格是运营/财务口径，改动应走部署配置与审计，不放进已有模型配置的加密文件；
  - 本切片不做汇率、缓存命中价、阶梯价，避免把「估算」做成伪精确。
- 单价单位统一为 **USD / 1M tokens**，成本四舍五入到 6 位小数；前端只展示，不参与计算。
- 未配置价格不是错误：接口仍返回 token 分账，`cost_usd=null`；这样灰度上线/未填价的环境不会 500。
- 不把 `model` 加进 `RunDetail`：本切片只解决汇总分账；单次 run 的模型归属留到后续（避免无谓扩大响应契约）。


`Settings.model_prices: dict[str, ModelPrice]`，环境变量示例：

```bash
PET_AGENT_MODEL_PRICES={"deepseek-chat":{"input_per_mtok":0.27,"output_per_mtok":1.10}}
```

### 3.2 领域与仓储

- 新增 `ModelUsage(model, runs, prompt_tokens, completion_tokens)`，`total_tokens` 为计算属性；
- `UsageOverview.by_model: list[ModelUsage]`；
- memory：遍历 succeeded run，按 `run.model or "unknown"` 聚合，按 total 降序、模型名升序；
- MySQL：`GROUP BY COALESCE(NULLIF(r.model,''),'unknown')`，排序与 memory 一致，复用同一 `where/since`。

### 3.3 API

`AdminUsageOut.by_model: list[AdminModelUsage]`，每行含 `model/runs/prompt_tokens/completion_tokens/total_tokens/cost_usd`。路由从 `request.app.state.settings.model_prices` 取价，调用 `estimate_cost_usd`。

### 3.4 管理端

`AdminUsage` 增加 `by_model`；`SessionList.vue` 增加表格：

| 模型 | 对话数 | Prompt | Completion | 合计 | 估算成本（USD） |
| --- | ---: | ---: | ---: | ---: | ---: |
| deepseek-chat | 12 | 8,400 | 3,100 | 11,500 | $0.005735 |

`cost_usd=null` 显示「未配置」；面板脚注说明 `PET_AGENT_MODEL_PRICES` 与单位。

## 5. 风险

- **MySQL 查询无本地真库验证**：无 `PET_AGENT_TEST_MYSQL_DSN` 时只跑 memory 契约；SQL 采用与现有 `by_day` 相同的 join/where，风险集中在 `GROUP BY` 别名与排序，报告需明示。
- **价格口径变化**：单价是配置快照，历史成本会随配置重算；本切片定位「当前估算」，不是财务结算账。
- **模型名漂移**：配置键必须与 `run.model` 完全一致；未匹配即 `null`，不会静默按 0 计。
- **成本精度**：浮点 + 6 位小数适合展示，不承诺账单级精度。
- **前端无测试框架**：管理端只有类型检查与构建证据，交互正确性靠代码审查；本切片不新增测试基建。

## 6. 非目标

- 不做按用户/会话分账、预算告警、汇率换算、缓存价；
- 不修改 Java `/api/v1` 与 `pet-lumina-app`；
- 不把价格写入数据库或管理端可编辑配置。
