# S1.42 · D10 第三刀：表单错误播报与热点卡片键盘化

- 批次：S1.42
- 日期：2026-11-26
- 状态：已完成
- 关联 BACKLOG：D10 全站可访问性收尾（剩余项中的「表单错误播报」「TrendingSlider 卡片/查看全部键盘化」「详情页作者头像键盘可达」）

## 目标

1. 表单校验失败时不再只弹一次性 Toast：新增表单内 `role="alert"` 错误区，输入补 `aria-invalid` / `aria-describedby`，提交失败后焦点落到首个缺失字段。覆盖 Login、SignUp、AddPet、AddReminder、EditProfile、AccountSecurity 六个页面。
2. `TrendingSlider`：标题与区域用 `aria-labelledby` 关联；「查看全部」与话题卡片改为真实链接（Tab 可聚焦、Enter 可进入）；自动播放尊重 hover/focus 与 `prefers-reduced-motion`；左右按钮有可读名称并在不可滚动时 `disabled`；装饰图 `alt=""`、圆点 `aria-hidden`。
3. `PostDetail` 作者头像与昵称：有 `post.user.id` 时改为 `RouterLink` 进入用户主页，键盘可达；无 id 时保持普通容器。
4. 用单测守住上述语义，防止后续改结构回退。

## 取舍

- **不做对比度扫描与真实 NVDA/VoiceOver 验收**：需要工具与真机，继续留在 BACKLOG；本轮只做可静态验证的语义修复。
- **不引入第三方表单库**：新增约 40 行的 `useFormA11y` + `FormError`，六个页面共用，避免各写一套错误状态机。
- **字段级只做 aria 关联与焦点，不逐字段内联错误**：错误文案仍集中在表单顶部一处（提交按钮上方），读屏通过 `aria-describedby` 关联；切片可控，也避免六个页面重复文案。
- **错误文案复用现有 i18n key**：只新增链接/按钮名称与热点区标题所需 key，不重写整套校验文案。
- **Toast 保留**：成功、接口失败等瞬态反馈继续用现有 Toast；表单校验错误改走内联 `role="alert"`。
- **不把自动播放做成可配置组件**：保持 4000ms 节奏，只加暂停与减弱动效判断。

## 验收标准

1. 新增测试全绿：
   - `FormError.spec.ts`：有消息渲染 `role="alert"` 且带 `id`；空消息不渲染。
   - `Login.form-a11y.spec.ts`：空提交出现 alert、两输入 `aria-invalid="true"`、焦点在手机号；填写后再次提交可清空错误；重复空提交仍重新播报。
   - `AddPet.form-a11y.spec.ts`：空提交 alert、名称/品种 `aria-invalid`、类型组 `aria-invalid`、焦点在名称；类型按钮 `aria-pressed`。
   - `TrendingSlider.a11y.spec.ts`：`region` 有可读名称；卡片为 `a[href="/topic/t1"]`；「查看全部」为 `a[href="/topics"]`；装饰图 `alt=""`；`prefers-reduced-motion` 下不自动改 index；自动轮播到末位时右按钮 `disabled`。
   - `PostDetail.a11y.spec.ts`：作者名与头像包在 `/user/u1` 链接内且 `aria-label` 可读；无作者 id 时不渲染该链接。

5. 三份 locale JSON 可被 `JSON.parse`，新增 key 三语齐全。

## 风险

- **jsdom 无 `window.matchMedia`**：组件内先判断 `typeof window.matchMedia === 'function'`，测试再按需 stub，避免直接抛错。
- **`scrollTo` 在 jsdom 不存在或不可用**：调用包在 try/catch 里，异常时退化为直接设置 `scrollLeft`。
- **`RouterLink` 改动 DOM**：卡片与头像外层由 `div` 变 `a`，需保留原有 `class` 与布局；单测断言 `href` 与名称，构建后仍需浏览器目视一次。
- **自动播放与 fake timers**：测试用 `vi.useFakeTimers()` 驱动 4000ms，断言 reduced-motion 时 index 不变；组件卸载清理 interval 防止测试间泄漏。
- **表单焦点**：六个页面提交失败后焦点移动可能影响鼠标用户，但这是读屏必需行为；仅在校验失败时触发，成功路径不变。
- **错误 id 唯一性**：模块级自增序号保证同页多实例不冲突；SSR 场景未涉及。
