# S1.21 图片生成桌宠（Image → Desk Pet）

**状态**：已完成（2026-11-08）。交付报告：[`docs/reports/2026-11-08-s1.21-image-pet.md`](../reports/2026-11-08-s1.21-image-pet.md)

## 0. 用户要什么

> 不好看，我需要的是可以根据图片生成一个桌宠

不是让我继续手绘一个角色，而是：**用户给一张图（自己的宠物、喜欢的角色、画的画），系统据此生成一个能站在首页右下角的桌宠**。

## 1. 这条路的三档实现与代价

| 档 | 做法 | 效果上限 | 代价 |
| --- | --- | --- | --- |
| **A 图像规整 + 程序化动效**（本轮） | 浏览器端抠背景 → 自动裁边 → 卡通化（保边平滑 + 色阶量化 + 描边）→ 生成精灵图；用呼吸 / 摇摆 / 视差 / 影子 / 点击反馈让它「活」起来 | 形象 100% 来自用户图片；动作是整图级的，没有骨骼形变，**眨眼、口型做不了** | 纯前端，零依赖、零算力、离线可用 |
| **B Live2D 绑定** | 把图片按头/身/发/眼切层，绑到 `.moc3` 模型上 | 真·灵动（眨眼、视线、头发飘） | 需要 Cubism 编辑器手工切层绑定，或接自动分层模型；单张任意图无法全自动 |
| **C 图生 3D（VRM）** | 单图 → 深度/法线 → 网格重建 → VRM | 可转身、可换装 | 需要 GPU + 生成模型（TripoSR/InstantMesh 类），本机没有 |

**本轮做 A，并把 B/C 的接口留出来**（精灵图来源可替换：`--sprite` 既可以是抠图结果，也可以是外部模型产出的分层资源）。

## 2. 管线（全部在前端，`pet-lumina-app/src/utils/petImage.ts`）

```text
File ──decode──▶ ImageData
   │
   ├─1. 背景移除：四角取色 → 与背景色距离 > 容差 且与边缘连通 → 透明
   │     （flood fill，避免把画面内部同色区域误删）
   ├─2. 自动裁边：按 alpha>阈值 求 bounding box，留 8px 边距
   ├─3. 卡通化：双边式保边平滑（简易 box blur + 权重）→ 色阶量化(levels) → 饱和度提升
   ├─4. 描边：Sobel 梯度 > 阈值 → 压暗为深色（可选开关）
   ├─5. 缩放：长边 ≤ 512（localStorage 友好），导出 PNG dataURL
   └─6. 存 sprite：{ id, dataUrl, width, height, createdAt, source: 'upload' }
```

参数可调（UI 三个滑杆）：`背景容差` / `色阶数量` / `描边强度`。默认值取「容差 32 / 6 阶 / 0.6」。

## 3. 动效（`DeskPet.vue` 的 `mode="sprite"`）

| 通道 | 实现 | 为什么 |
| --- | --- | --- |
| 呼吸 | `scale(1 → 1.015)` 3.8s | 整图可做，不破坏造型 |
| 摇摆 | `rotate(-1.2° → 1.2°)` 4.6s，与呼吸错相 | 制造「重心在动」的错觉 |
| 视差 | 指针位置 → `translate(±4px, ±3px)`，rAF 平滑 | 替代「视线跟随」——单图没有眼睛可动 |
| 影子 | 椭圆 `scaleX` 随呼吸反向缩放 | 让画面有「贴地」关系 |
| 点击 | 跳跃（WAAPI）+ 爱心 + 气泡 | 保留 v2 的反馈手感 |
| 拖拽 / 双击收起 | 复用 v2 | 一致 |

> 说明：单张图片无法拆出眼睛，**不做假眨眼**（在整图上贴一条黑线只会更假）。

## 4. 存储与隐私

- 精灵图存 `localStorage['petlumina-deskpet-sprite']`（PNG dataURL，512px 上限，实测 < 300KB）。
- **不上传服务器**：图片处理全在浏览器 canvas 里，服务端只存业务数据。
- 提供「恢复默认形象」与「删除我的桌宠图」，删除即从 localStorage 移除。

## 6. 验收（可执行）

1. `npx vue-tsc -b` exit 0。
2. `npx vitest run`：新增 ≥ 12 例（抠背景/裁边/量化/描边/缩放/store），全绿。
3. `npm run build` 通过，`DeskPet-*.js` 体积不爆（< 30KB）。
4. 浏览器：上传一张带白底的图 → 预览出现透明底卡通化形象 → 保存 → 回首页右下角变成该形象 → 点击有跳跃与气泡 → 刷新后仍在。
5. 「恢复默认」后回到内置角色，localStorage 键被移除。

## 7. 风险

| 风险 | 应对 |
| --- | --- |
| 复杂背景抠不干净 | 四角 flood fill + 容差滑杆 + 手动「保留/擦除」留到下一版；先如实说明局限 |
| 卡通化把人像弄糊 | 色阶与描边都可关，默认保守（6 阶、描边 0.6） |
| dataURL 撑爆 localStorage | 长边 512 + 保存前 `try/catch` 配额检测，失败提示「图太大，换小图」 |
| jsdom 无 canvas | 纯函数只吃 `{data,width,height}`，不依赖 DOM canvas；DOM 部分单独兜底 |
