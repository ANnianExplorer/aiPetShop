# S1.32 浏览器 e2e 自动化（BACKLOG C9）

- 批次：S1.32
- 对应：BACKLOG C9「前端 e2e 自动化」
- 状态：已完成（证据见 `docs/reports/2026-11-18-s1.32-browser-e2e.md`）

## 目标

把目前只能手动开 Edge 点的三条关键链路，变成一条命令可重复执行的 Playwright 测试：

1. App：登录 → 对话 → 看到引用 → 点击引用回跳。
2. 管理端：管理员登录 → 会话列表 → 会话详情（对话流 + 引用 + 运行轨迹）。
3. App：触发 429 → 看到「请求太频繁」提示 → 出现重试按钮。

测试跑在固定桩数据上，不依赖真实 LLM、真实 Java 后端或 MySQL。

## 做法与取舍

- **Playwright + 系统 Edge**：使用 `channel: 'msedge'`，不下载 Playwright Chromium。本机已装 Edge，省下载体积与时间；代价是该套件目前是 Windows/Edge 环境专用。
- **固定桩**：复用 `backend-agent/tests/stub_java.py`（8080）、`stub_llm.py`（8098）与真实 Agent 进程（8099），App 走 Vite（5174），管理端走 Vite（3000，proxy `/api` → 8080）。
- **单 worker、串行**：管理端用例依赖 App 用例创建的会话；429 用例改 `PET_AGENT_RATE_LIMIT_PER_MINUTE=1`，并让两个 App 用例用不同手机号（不同 user_id）隔离限流。
- **只加测试选择器**：给登录、对话、引用、错误区、管理端列表/详情加 `data-testid`，不改业务逻辑；用例一律用 testid，不依赖易变文案。
- **一条命令启动/清理**：`pet-lumina-app/scripts/e2e-stack.ps1` 负责起 5 个进程、健康检查、跑 Playwright，并在 `finally` 中按进程树清理；日志写 `%TEMP%`。
- **不把 e2e 塞进现有 CI**：当前 CI 没有 Windows + Edge 环境，本轮先交付本地可重复执行的基座；CI 接入作为后续事项写回 BACKLOG。

## 验收标准

1. `powershell -ExecutionPolicy Bypass -File pet-lumina-app/scripts/e2e-stack.ps1` 启动全栈并跑完 3 条用例，退出码 0。
2. 用例 1：手机 `13800001001` 登录 → `/chat` → 发送「帮我看看疫苗记录」→ 助手出现「9月1日打过疫苗」→ 引用按钮显示「疫苗记录」→ 点击后 URL 变为 `#/log/7001`。
3. 用例 2：管理员 `13900000000` 登录 → `/agent/sessions` → 打开刚创建的会话 → 详情出现对话消息、引用「疫苗记录」、运行轨迹区块。
4. 用例 3：手机 `13800001002` 登录 → 第一问成功 → 第二问出现「请求太频繁，请稍后再试」与重试按钮；点击重试仍得到限流提示（窗口内）。
5. `pet-lumina-app` 的 `npx vue-tsc -b`、`npx vitest run`、`npm run build` 通过；`pet-lumina-web` 的 `npx vue-tsc -b`、`npm run build` 通过。
6. 测试结束无残留 node/uvicorn/vite 进程；仓库无 `.tmp-`/`test-results`/`playwright-report` 残留；`git status --porcelain` 仅 `?? .vscode/`。

## 风险

- Edge headless 若被本机策略限制，fallback 到 `headless: false` 并如实记录；不假装通过。
- 管理端 Vite proxy 写死 `localhost:8080`，Node 可能解析到 IPv6 `::1`；uvicorn 监听 `0.0.0.0` 或同时兼容 IPv4/IPv6。
- 429 用例依赖进程内限流与单 worker；若 60 秒窗口边界抖动，用例改用独立 agent 实例或放宽断言，但不删验收项。
- 登录页有外部背景图，测试统一 `waitUntil: 'domcontentloaded'` 并拦截非本机请求，避免网络拖慢。
- 两小时预算内若管理端用例跑不通，保留 App 两条真实通过用例，把管理员用例写回 BACKLOG，不假绿。

## 不做

- 不下载 Playwright 浏览器、不接 CI runner。
- 不覆盖全部页面、不做视觉回归、不测真实 LLM 质量。
- 不重构聊天/管理端业务代码，只加测试选择器与 e2e 资产。
