# S1.40 · D10 第二刀：路由标题与卡片键盘语义

- 批次：S1.40
- 日期：2026-11-24
- 状态：实施中
- 关联 BACKLOG：D10 全站可访问性收尾（剩余项中的「路由 document.title」「社区/日志卡片点击区」「图片 alt」）

## 目标

1. 每个具名路由在进入后把 `document.title` 更新为「页面名 · PetLumina」；切换语言后标题同步刷新。
2. 社区帖子卡片、生活记录卡片从 `div @click` 改为真正的链接（`RouterLink`），支持 Tab 聚焦、Enter 激活、读屏识别为链接。
3. 卡片与页面头部图片补 `alt`：装饰性头像 `alt=""`，内容图使用可读描述；纯图标按钮补 `aria-label`。
4. 用单测守住「路由标题映射全覆盖」与「卡片是链接 + 可读名称」，防止后续新增路由/改结构时回退。

## 取舍

- **不引入第三方 a11y 插件**：本轮只做可静态验证的语义修复，对比度扫描与 NVDA/VoiceOver 人工验收仍留在 BACKLOG。
- **不做全局路由守卫改标题**：用 `router.afterEach` 单点安装，避免守卫里混入展示逻辑；语言切换通过 `watch` 复用同一套纯函数。
- **页面头部头像 `alt=""`**：头像紧邻用户名文本，重复播报反而噪音；卡片内帖子图/生活记录图是内容，必须描述。
- **不动 TrendingSlider**：其「查看全部」与话题卡片同属 D10 剩余，避免本轮切片过大。

## 验收标准

1. `npx vitest run` 全绿，且新增：
   - `src/utils/pageTitle.spec.ts`：格式化、未知路由、真实 router 全路由覆盖、三语 key 齐全、locale 切换刷新标题。
   - `src/components/community/PostFeed.a11y.spec.ts`：卡片渲染为 `<a>`、`aria-label` 含作者与摘要、图片 `alt`、按钮名称。
   - `src/components/lifelog/LogCard.a11y.spec.ts`：卡片渲染为 `<a>`、`aria-label` 含标题、图片 `alt`、装饰图标 `aria-hidden`。
2. `npx vue-tsc -b` 退出码 0。
3. `npm run build` 退出码 0。
4. 三份 locale JSON 可被 `JSON.parse`，`pageTitle` 键数量一致。

## 风险

- 把 `div @click` 换成 `RouterLink` 会改变 DOM 与默认样式（下划线/颜色）；用 `class="block"` 与继承样式控制，测试断言视觉类仍在。
- `router.afterEach` 注册在模块加载时，测试若重复导入可能重复注册；`installDocumentTitle` 返回停止函数，单测内及时清理。
- `i18n.global.locale` 在 legacy:false 下是 `WritableComputedRef`，工具参数按只读 `{ value: string }` 接收，避免类型不兼容。
- 语言包键遗漏会在运行时回退显示 key；用「三语全覆盖」单测拦截。
